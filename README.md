# تطبيق إذاعة القرآن الكريم والمكتبة الصوتية الشاملة

تحديث متكامل لتطبيق راديو القرآن الكريم يعتمد بالكامل على استهلاك خوادم واجهة برمجة التطبيقات المجانية لشبكة **MP3Quran API v3** الشهيرة بدلاً من تخزين الملفات الصوتية محلياً.

---

## المكونات والميزات الرئيسية

1. **واجهة أمامية تفاعلية حديثة (`index.html` & `script.js` & `styles.css`)**:
   - تصميم ذو طابع إسلامي راقي بنظام الصفحة الواحدة (Single Page App) باستخدام إطار عمل **Tailwind CSS**.
   - قسم البث الإذاعي الحي في الأعلى لتشغيل أكثر من 150 محطة إذاعية حية متوفرة في واجهة API.
   - قسم المكتبة الصوتية الشاملة (On-Demand Library) للبحث عن القراء، وتحديد الروايات (مثل حفص عن عاصم، ورش، قالون، إلخ)، واختيار السورة المناسبة للاستماع المباشر.
   - مشغل صوتي مخصص يتفاعل تلقائياً مع الذبذبات الصوتية للقرآن الكريم عبر لوحة عرض بصرية ثلاثية الأبعاد (Canvas Audio Visualizer) تعمل بواسطة `AudioContext`.
   - كتم الصوت، مستوى صوت ذكي، شريط تقدم زمني قابل للسحب (للسور فقط)، والتنقل التلقائي بين السور المتعاقبة.

2. **برنامج بث الراديو الآلي الخلفي (`streamer.py`)**:
   - كود بايثون متقدم يقوم بسحب روابط تلاوات السور لقارئ معين تلقائياً عبر API.
   - إنشاء قائمة تشغيل مؤقتة وضخها إلى محول البث الشهير `ffmpeg` بهدف البث المباشر المتواصل 24/7 دون أي انقطاع إلى خادم Icecast/Shoutcast.
   - إعادة ترميز المسارات تلقائياً إلى معدل بت موحد (128kbps Stereo) لضمان استقرار البث لجميع المستخدمين بصرف النظر عن تفاوت دقة الملف الأصلي.

3. **حاوية خادم البث المحلي (`docker-compose.yml`)**:
   - ملف لتشغيل خادم Icecast2 محلياً في ثوانٍ باستخدام Docker Compose لاختبار برنامج البث بسهولة قبل رفعه للإنتاج.

## متطلبات التشغيل

### 1. تشغيل الواجهة الأمامية (Frontend)
تحتاج فقط لخادم ويب بسيط لعرض الملفات لتجنب قيود الحظر المحلي في المتصفح عند تحميل الملفات عبر `file://`:
* **باستخدام Python**:
  ```bash
  python -m http.server 3000
  ```
* **باستخدام Node.js**:
  ```bash
  npx http-server -p 3000
  ```
افتح المتصفح وتوجه إلى الرابط التالي: `http://localhost:3000`.

### 2. تشغيل خادم البث Icecast (Backend)
إذا كنت ترغب في تشغيل بث مباشر آلي خاص بك على مدار الساعة:
1. تأكد من تشغيل حاوية Docker:
   ```bash
   docker compose up -d
   ```
2. سيكون خادم Icecast متاحاً الآن على الرابط: `http://localhost:8000`.
   - اسم مستخدم البث الافتراضي: `source`
   - كلمة مرور البث: `hackme`
   - لوحة تحكم المدير: `http://localhost:8000` (المستخدم: `admin` / المرور: `admin`).

### 3. تشغيل برنامج البث الآلي (Python Streamer)
* **المتطلبات الأساسية**:
  - يجب تثبيت برنامج `ffmpeg` وإضافته لمتغيرات البيئة للكونسول (PATH).
    * للويندوز: يمكن تحميله عبر `winget install Gyan.FFmpeg` أو من موقع ffmpeg الرسمي.
    * للينكس/ماك: `sudo apt install ffmpeg` أو `brew install ffmpeg`.

* **تشغيل السكربت**:
  ```bash
  python streamer.py --host localhost --port 8000 --password hackme --mount /live
  ```
  عند بدء السكربت، سيعرض لك قائمة تضم أشهر 30 قارئًا. ادخل معرف القارئ (مثل `1` لـ إبراهيم الأخضر) واضغط **Enter** لبدء البث المباشر.

* **خيارات إضافية**:
  - للبث العشوائي لترتيب السور: `--shuffle`
  - لتحديد معرف القارئ مباشرة دون مطالبة تفاعلية: `--reciter 1`
  - للتحكم بمعدل دقة الصوت المستهدف: `--bitrate 192` (الافتراضي 128)

## تفاصيل واجهة برمجيات MP3Quran API v3 المستهلكة
- **بيانات السور وأسماؤها وتفاصيل الصفحات**: `https://mp3quran.net/api/v3/suwar?language=ar`
- **بيانات القراء ورواياتهم وخوادم التلاوة**: `https://mp3quran.net/api/v3/reciters?language=ar`
- **بيانات محطات الإذاعة الحية**: `https://mp3quran.net/api/v3/radios?language=ar`
- **رابط التلاوة المباشر للمكتبة**: `[SERVER_URL][THREE_DIGIT_SURAH_ID].mp3` (مثال: `https://server6.mp3quran.net/akdr/001.mp3`)
